# Play Union website

Multi-page Astro site for Play Union — indoor pretend-play and craft space in Somerville, MA.

## Quick start

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Pages

- `/` Home
- `/visit/` Visit & Open Play
- `/passes/` Passes & Memberships
- `/classes-events/` Classes & Events
- `/private-events/` Private Events (+ birthday parties, other rentals, partnerships)
- `/about/` About
- `/contact/` Contact (single form with reason selector)
- `/faq/` FAQ

See **OWNER-REVIEW.md** before publishing.

## Stack

Astro static site. Editable business data lives in `src/data/`. Brand logo and space photos live in `public/images/`.
